# Plano de Lançamento

## Tese de Lançamento

Todo mundo está usando IA para escrever. Mas toda IA faz todo mundo soar igual. Cultiv resolve isso: mede como você escreve e usa essas métricas como guardrails para gerar texto que soa como você. Não é mais um "AI writing tool" — é a primeira ferramenta que QUANTIFICA sua voz.

## A Onda

- **AI writing tools** explodindo (ChatGPT, Jasper, Copy.ai, etc.)
- **Problema emergente:** todos os textos começam a soar iguais
- **Trending:** "AI-generated content detection" — empresas querendo saber se texto é IA
- **Solução:** Cultiv gera texto que é indistinguível do autor porque é CONSTRAINED pelo perfil métrico do autor
- **Timing:** agora, enquanto o mercado percebe o problema de homogeneização

```

- Consistency score médio
```

## Pós-Lançamento — Loops

### Visitante → Usuário
1. Visita landing page
2. Experimenta demo interativo (cola texto, vê métricas)
3. Clica "Começar grátis"
4. Cria conta
5. Completa wizard (10-15 min)
6. Vê perfil de voz completo

### Usuário → Pagante
1. Completa wizard
2. Gera 1-2 textos de teste (se houver quota inicial)
3. Vê que funciona
4. Precisa de mais gerações
5. Assina plano (R$49-199/mês)

### Pagante → Advocacy
1. Gera conteúdo regularmente
2. Publica em redes sociais
3. Resultados: engajamento, seguidores, leads
4. Conta para outros criadores
5. Indica o Cultiv

### Loops de Retenção
- **Email:** "Você usou X de Y gerações este mês. Precisa de mais?"
- **Notificação:** "Seu perfil de voz foi atualizado com novos exemplos."
- **Content:** Blog posts sobre voz autoral, escrita com IA
- **Community:** Grupo de usuários compartilhando resultados
