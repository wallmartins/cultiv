# Referencial Teórico — Motor de Identificação de Padrões de Escrita

Este documento consolida os artigos acadêmicos que fundamentam o redesign do motor de identificação de padrões do autor e do wizard de calibração.

---

## Visão Geral

O motor de identificação do Cultiv precisa resolver um problema central: **extrair padrões de escrita robustos e transferíveis a partir de textos genuínos do autor**, separando estilo autêntico de variação topical e de canal. A literatura de estilometria computacional e autoria oferece tanto as ferramentas de extração quanto as métricas de validação necessárias.

---

## Artigo 1: Stylometry recognizes human and LLM-generated texts in short samples

**Referência:** Przystalski et al., 2025 — arXiv:2507.00838

### Contexto

Utiliza estilometria para distinguir textos gerados por LLMs de textos humanos, criando um benchmark com textos baseados em Wikipedia processados por GPT-3.5/4, LLaMa 2/3, Orca e Falcon.

### Metodologia

- **Features StyloMetrix:** pipeline de features humanas cobrindo padrões lexicais, gramaticais, sintáticos e de pontuação
- **Features de n-gramas:** pipeline próprio baseado em n-gramas de caracteres e palavras
- **Classificadores:** Decision Trees e LightGBM
- **Explicabilidade:** SHAP (Shapley Additive Explanations) para identificar quais features diferenciam autores

### Achados Relevantes para o Cultiv

1. **LLMs geram texto com maior padronização gramatical** que humanos — os humanos mostram mais irregularidade e variedade. Isso implica que o prompt de geração precisa compensar essa tendência injetando variância controlada.

2. **Features de pontuação** (travessões, reticências, parênteses) são preditores fortes de autoria em textos curtos — devem ser capturadas na Etapa 1 do wizard.

3. **SHAP identifica overused words** como marcadores de LLM — o perfil do autor deve incluir anti-padrões que evitem essas palavras genéricas.

4. **Acurácia de 0.87 MCC** em classificação multiclasse (7 classes) e até 0.98 em binária — valida que features estilométricas são suficientemente discriminativas.

### Aplicação Direta

- Extração determinística de features lexicais, gramaticais e de pontuação como ground truth
- Anti-padrões derivados de features que SHAP identifica como genéricas de LLM
- Validação de que o texto gerado mantém irregularidades humanas

## Artigo 2: Linguistic and Embedding-Based Profiling of Texts generated by Humans and Large Language Models

**Referência:** Zanotto & Aroyehun, 2025 — arXiv:2507.13614

### Contexto

Analisa diferenças linguísticas entre textos humanos e gerados por LLMs usando features em múltiplos níveis linguísticos (morfologia, sintaxe, semântica) e style embeddings, em 8 domínios e 11 modelos.

### Metodologia

- **Features linguísticas multi-nível:**
  - Textual: comprimento de texto, comprimento de frase
  - Morfológica: Morphological Complexity Index (MCI)
  - Sintática: profundidade da árvore de dependência, comprimento de dependência
  - Léxica: prevalência de palavras, type-token ratio
  - Semântica: similaridade semântica, emotionalidade
- **Style Embeddings:** modelo de Patel et al. (2025) para representar estilos vetorialmente
- **Análise de variância:** desvio padrão da distância euclidiana entre features

### Achados Relevantes para o Cultiv

1. **Humanos mostram maior variabilidade estilística que LLMs** — a variância é uma feature, não um bug. O perfil do autor deve capturar essa variância, não apenas médias.

2. **LLMs mais recentes tendem à homogeneização** — outputs cada vez mais similares entre si. O wizard precisa detectar quando o autor está写作 de forma genérica vs. com voz autêntica.

3. **Novos modelos (chat) outputs textos com variabilidade similar a humanos** — a fronteira entre humano e máquina está se estreitando, tornando a extração determinística mais importante.

4. **PCA dos style embeddings** mostra agrupamento por modelo, não por domínio — valida que estilo é mais identificador que tópico.

### Aplicação Direta

- Cálculo de `consistencyScore` como desvio padrão inverso das features entre textos do wizard
- Style embeddings para medir distância entre textos do autor e detectar outliers
- Variância como sinal de qualidade (muito baixa = genérico, muito alta = inconsistente)

## Artigo 3: LLM one-shot style transfer for Authorship Attribution and Verification

**Referência:** Miralles-González et al., 2025 — arXiv:2510.13302

### Contexto

Propõe abordagem não-supervisada (OSST) que usa log-probabilidades de LLMs para medir transferabilidade de estilo entre textos, sem necessidade de dados rotulados.

### Metodologia

- **OSST Score:** mede quão útil o estilo de um exemplo one-shot é para restaurar um texto neutralizado
- **Neutralização:** LLM remove o estilo de um texto, mantendo o conteúdo
- **Restauração:** LLM tenta restaurar o estilo original usando one-shot
- **Log-probabilidades:** a média das log-prob do texto alvo reflete a transferabilidade do estilo

### Achados Relevantes para o Cultiv

1. **Separação estilo vs. tópico:** o método neutraliza o conteúdo e mede apenas o estilo — valida que estilo e tópico são camadas separáveis.

2. **Performance escala com tamanho do modelo** — modelos maiores capturam melhor a transferibilidade de estilo.

3. **Método é zero-shot para atribuição** — não precisa de dados de treinamento, apenas exemplos do autor.

4. **Validação multilíngue** — funciona em português e inglês, alinhando com o bilinguismo do Cultiv.

### Aplicação Direta

- `topicIndependenceScore`: neutralizar cada texto do wizard e medir se o estilo é restaurável
- Validação de que os 5 textos do wizard capturam estilo transferível, não apenas conteúdo
- Base teórica para o wizard com temas variados (cada tema é uma oportunidade de validar transferibilidade)

## Artigo 4: Trends and Challenges in Authorship Analysis

**Referência:** Habib et al., 2025 — arXiv:2505.15422

### Contexto

Revisão sistemática da literatura de 2015-2024 cobrindo atribuição e verificação de autoria, desde ML tradicional até LLMs.

### Achados Relevantes para o Cultiv

1. **Catálogo de features:** n-gramas lexicais/char, POS tags, dependências sintáticas, distribuições de comprimento, features semânticas — serve como checklist para a extração determinística.

2. **Lacunas identificadas:** processamento de linguagens de baixo recurso, adaptação multilíngue, generalização cross-domain — alinha com o bilinguismo pt-BR/en do Cultiv.

3. **Evolução de métodos:** de features manuais → transformers → LLMs — valida a abordagem híbrida (determinística + LLM).

4. **Detecção de texto gerado por IA** como campo emergente — o perfil do autor deve servir também como baseline para detectar quando o texto gerado está se desviando.

### Aplicação Direta

- Checklist completo de features para a camada de extração determinística
- Validação de que a abordagem híbrida (determinística + LLM) está alinhada com o estado da arte

## Artigo 5: Detection of changes in literary writing style using N-grams

**Referência:** Ríos-Toledo et al., 2022 — PubMed:35857768

### Contexto

Avalia n-gramas (palavras, caracteres, POS tags, relações sintáticas) como markers de estilo para detectar mudanças temporais em romances de 11 autores.

### Metodologia

- **4 tipos de n-gramas:** caracteres, palavras, POS tags, relações sintáticas
- **Classificador:** Logistic Regression
- **Redução de dimensionalidade:** PCA e LSA
- **Organização cronológica:** textos iniciais vs. finais por autor

### Achados Relevantes para o Cultiv

1. **Todos os autores mostraram mudanças significativas de estilo ao longo do tempo** — o perfil do autor não é estático, deve evoluir.

2. **N-gramas de relações sintáticas**achievm resultados competitivos e são **independentes de tópico** — features sintáticas são mais confiáveis que lexicais para medir consistência.

3. **PCA e LSA** funcionam para reduzir dimensionalidade mantendo poder discriminativo — aplicável à compressão do perfil.

### Aplicação Direta

- N-gramas sintáticos como features topic-independent para `topicIndependenceScore`
- Base para detectar evolução temporal do autor (perfil deve ser recalculável)
- Validação de que features sintáticas são mais estáveis que lexicais

## Artigo 6: Comparing writing style feature-based classification methods

**Referência:** Suh, 2016 — PubMed:27006870

### Contexto

Compara 4 tipos de features de estilo (lexicais, sintáticas, estruturais, de conteúdo) e 8 técnicas de classificação para estimar reputação de usuários em redes sociais.

### Achados Relevantes para o Cultiv

1. **Features de conteúdo precisam ser separadas de features de estilo** — confirma que o perfil não deve incluir informações topicas.

2. **Ensemble learning (RS-SVM) supera classificadores base** — abordagens combinadas são mais robustas.

3. **Abordagem "portfolio" para definição de classes** dá melhor acurácia — múltiplas perspectivas de avaliação são superiores a uma única métrica.

### Aplicação Direta

- Separação explícita de features de estilo vs. conteúdo na extração determinística
- Abordagem "portfolio" para calcular confidence (múltiplos sinais, não uma única métrica)

## Artigo 7: Unveiling ChatGPT text using writing style

**Referência:** Berriche & Larabi-Marie-Sainte, 2024 — PubMed:38984302

### Contexto

Usa features estilométricas intrínsecas com XGBoost para detectar texto gerado por ChatGPT, alcançando 100% de acurácia.

### Achados Relevantes para o Cultiv

1. **Features estilométricas intrínsecas** (não TF-IDF) são superiores — validam a abordagem de features determinísticas.

2. **XGBoost com tuning** alcança performance máxima — classificadores baseados em árvores são eficazes para features estilométricas.

3. **Documentos mistos** (parágrafos humanos + ChatGPT) são classificados com 98% de acurácia — valida que o wizard pode detectar textos híbridos.

### Aplicação Direta

- Features intrínsecas como base da extração determinística
- Validação de que o wizard pode detectar quando o autor está "escrevendo como LLM"

## Artigo 8: Stylometry for real-world expert coders

**Referência:** Gurioli et al., 2024 — PubMed:39650415

### Contexto

Aplica estilometria a código-fonte real, reconhecendo autores out-of-distribution com k-NN.

### Achados Relevantes para o Cultiv

1. **Reconhecimento de autores out-of-distribution** — o sistema deve funcionar para autores nunca vistos, não apenas para perfis pré-treinados.

2. **Dataset de 114.400 snippets, 104 autores** — escala real de dados necessária para validação.

3. **Performance consistente entre in-distribution e out-of-distribution** — o wizard não precisa de exemplos anteriores do autor para funcionar.

### Aplicação Direta

- Validação de que o wizard em 5 etapas é suficiente para criar um perfil novo (cold start)
- k-NN como baseline para medir similaridade entre textos do wizard

## Artigo 9: Stylometry and forensic science

**Referência:** Cammarota et al., 2024 — PubMed:39781110

### Contexto

Revisão de estilometria aplicada à ciência forense, discutindo lacunas em procedimentos probabilísticos.

### Achados Relevantes para o Cultiv

1. **Procedimento probabilístico para avaliar valor probatório** — o perfil do autor deve ter uma métrica de confiabilidade que seja interpretável.

2. **Critérios de organizações internacionais (ENFSI)** — padrões de qualidade para métodos estilométricos.

3. **Aceitação em processos judiciais** — evidencia que estilometria é uma ciência madura quando bem fundamentada.

### Aplicação Direta

- Base para o cálculo de `Voice Confidence` como métrica probabilística interpretável
- Padrões de qualidade para validar o motor de identificação

## Artigo 10: Gender classification in classical fiction

**Referência:** Zhu et al., 2022 — PubMed:35942740

### Contexto

Usa frequência de palavras para classificar gênero do autor em 1.113 ficções clássicas com 92% de acurácia.

### Achados Relevantes para o Cultiv

1. **Features simples (frequência de palavras) podem ser surpreendentemente poderosas** — nem tudo precisa ser deep learning.

2. **Nacionalidade não é impactante** — o estilo é "universal" dentro de um idioma, validando que features linguísticas são mais importantes que contexto geográfico.

3. **Corpus grande (1.113 textos)** — mostra que mais dados melhoram a classificação, mas o wizard com 5 textos pode ser suficiente para cold start.

### Aplicação Direta

- Validação de que features simples (frequência, comprimento) devem fazer parte da extração determinística
- Não supercomplicar: features lexicais básicas já têm poder discriminativo

## Síntese: Princípios para o Motor de Identificação

A partir dos 10 artigos, emergem 6 princípios orientadores:

### 1. Extração Híbrida (Determinística + LLM)
- Features numéricas extraídas deterministicamente servem de ground truth
- LLM interpreta e sintetiza em narrativa legível
- Nenhuma das duas camadas é suficiente sozinha

### 2. Separação Estilo vs. Tópico
- Features sintáticas (dependency depth, POS distribution) são mais topic-independent que lexicais
- Neutralização de tópico valida transferibilidade do estilo
- Perfil não deve conter informação topical

### 3. Consistência como Qualidade
- Variância entre textos do wizard mede confiabilidade
- Muito baixa = genérico (padrão LLM), muito alta = inconsistente
- Sweet spot: variância moderada com features topic-independent estáveis

### 4. Cold Start com Wizard Guiado
- 5 textos de tamanhos e temas variados são suficientes para cold start
- Cada etapa do wizard captura camadas específicas do perfil
- Textos genuínos do autor (não híbridos editados) são essenciais

### 5. Confidence Composta
- Não baseada apenas em contagem de exemplos
- Incorpora consistência, independência topical, qualidade de extração
- Métrica probabilística interpretável

### 6. Anti-padrões como Guardrails
- LLMs geram texto mais padronizado que humanos
- Perfil deve incluir irregularidades e anti-padrões do autor
- Prompt de geração usa features quantitativas como limites
