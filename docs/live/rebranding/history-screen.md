Com base no **Prompt 0 – Design System da Cultiv**, crie o rebranding da tela de histórico de gerações.

**OBJETIVO DA TELA:** Permitir que o usuário visualize, filtre e acesse todas as suas "expedições" (textos gerados) anteriores.

**METÁFORA ESPECÍFICA:** O "Caderno de Bordo" do explorador — um registro de todas as jornadas já realizadas.

**ESTRUTURA:**
- **Título:** "Caderno de bordo"
- **Subtítulo:** "Todas as suas expedições em um só lugar."
- **Filtros:** Por período (data), por status (Concluída, Em andamento, Rascunho), por formato (tipo de expedição).
- **Tabela/Lista:**
  - Colunas: "Expedição" (formato), "Data de partida", "Status".
  - Cada linha é clicável para abrir o texto gerado.
- **Botão:** "Nova expedição" (primário) — leva para a tela de geração (Prompt 2).

**REGRAS DE IMPLEMENTAÇÃO:**
- A tabela deve ser responsiva, com design limpo e legível.
- Use tags visuais para os status (ex: bolinha verde para "Concluída", amarela para "Em andamento").
- Os filtros podem ser dropdowns ou botões de toggle.
- Aplique o sistema de design (cores, tipografia, espaçamento).
