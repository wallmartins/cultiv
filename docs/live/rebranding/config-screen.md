Com base no **Prompt 0 – Design System da Cultiv**, crie o rebranding da tela de configurações do usuário.

**OBJETIVO DA TELA:** Permitir que o usuário gerencie seus dados pessoais, idioma e privacidade.

**METÁFORA ESPECÍFICA:** "Ajustes de Navegação" — as calibrações finas do mapa e da bússola.

**ESTRUTURA:**
- **Título:** "Ajustes de navegação"

- **Campo 1:** "Identidade do explorador" — exibe o email do usuário (apenas leitura).

- **Campo 2:** "Idioma do mapa" — seletor de idioma da interface (ex: Português, Inglês).

- **Campo 3:** "Apagar pegadas" — botão para revogar consentimento de uso de dados e exemplos. Deve abrir um modal de confirmação.

- **Botão:** "Salvar ajustes" (primário).

**REGRAS DE IMPLEMENTAÇÃO:**
- Use uma lista simples e limpa de itens de configuração.
- O botão "Apagar pegadas" deve ser visualmente distinto (ex: em vermelho ou com borda destacada) para sinalizar ação crítica.
- Aplique o sistema de design.
