## 2. Fraquezas Reais (de reclamações, não de suposições)

### Voz Genérica — O problema nº 1

> *"Soa tudo igual, parece que a IA escreveu."*

ChatGPT não preserva voz autoral. Quando 100 pessoas usam o mesmo prompt, os outputs se parecem.

### Privacidade e dados

> *"Minha empresa não pode usar porque os dados vão pra OpenAI."*

OpenAI usa dados de treino por padrão (opt-out disponível). Para founders que publicam ideias estratégicas, isso é um risco real.

### Preço Pro é absurdo

> *"R$1.100/mês pra um indivíduo? Tá doido."*

ChatGPT Pro (US$200/mês ≈ R$1.100+) é inacessível pra maioria dos profissionais solo.

### Não resolve o problema do autor

> *"Uso todo dia mas tenho que reescrever tudo que ele gera."*

Autores gastam mais tempo reescrevendo o output do ChatGPT do que escreveriam sozinhos.

## 3. Nossas Vantagens (o que eles NÃO têm)

| Cultiv | ChatGPT |
|--------|---------|
| **Assina como você pensa** (Reasoning Signature + Argument Development) | Lembra o que você pediu, não como você pensa |
| **14 métricas determinísticas** de escrita (sem LLM) | Zero métricas — output é caixa-preta |
| **Calibração guiada** em 15 minutos (wizard de 5 etapas) | Prompt engineering manual, sem estrutura |
| **Voice Judge** com provider separado pra evitar self-bias | Sem verificação de voz |
| **Anti-padrões derivados automaticamente** do seu portfólio | Não aprende o que você evita |
| **Foco total em escrita autoral** | Assistente universal que "também escreve" |
| **Privacidade por design** — dados ficam no seu workspace | Dados vão pra OpenAI por padrão |
| **Preço previsível** — assinatura com cota mensal | Preços que mudam e tiers confusos |

### 3 Camadas que o ChatGPT não tem

1. **Core Reasoning Signature** — como você pensa (certeza, julgamento, ritmo de conclusão)
2. **Argument Development Signature** — como você desenvolve um texto (movimentos típicos, transições, postura epistêmica)
3. **Format Expression Profile** — como você soa em cada canal (formal, informal, técnico)

## 5. Jogos Vencedores por Cenário

### "ChatGPT é mais barato"

> "ChatGPT Plus custa R$110/mês e gera texto genérico que você precisa reescrever. Cultiv custa R$99/mês e gera texto que soa como você. Quanto vale o tempo que você gasta reescrevendo todo dia?"

### "ChatGPT faz tudo, Cultiv só escreve"

> "Exatamente por isso. ChatGPT é o canivete suíço — faz tudo, nada excepcionalmente. Cultiv é a ferramenta que resolve o problema que mais te incomoda: escrever algo que soa como você."

### "Já tenho ChatGPT, não preciso de mais uma ferramenta"

> "Cultiv não substitui o ChatGPT. Usa o ChatGPT pra pesquisar, planejar, resolver problemas. Usa Cultiv pra escrever textos que são seus. São ferramentas pra coisas diferentes."

### "Meus clientes se importam se eu uso IA?"

> "Se o conteúdo soa como você, não. Se soa como ChatGPT, sim. O problema não é usar IA — é usar IA que apaga sua voz."

### "Vou testar o ChatGPT primeiro"

> "Claro. Mas teste com um post real — escreva algo que você normalmente escreveria, depois peça pro ChatGPT gerar o mesmo. Compare. Se o output soa como você, ótimo. Se não, a gente conversa."
