- `skills/*.md` – concise guidelines for TypeScript, React, Effect-TS, Testing.

## Rules (always applied)
- `rules/workflow-core.mdc` – PRD/ADR/Issues workflow, memory bank loading.
- `rules/memory-bank.mdc` – defines memory-bank/ structure and update rules.

Example: `@references/effect-core.md`
